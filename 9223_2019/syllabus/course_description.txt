Title: Algorithmic Machine Learning and Data Science

Description: This course gives a behind-the-scenes look into the algorithms and computational methods that make machine learning and data science work at large scale. How does a service like Shazam match a sound clip to a library of 100 million songs in under a second? How do scientists find patterns in terabytes of genetic data? How can we efficiently train neural networks with millions of parameters on millions of labeled images? We will address these questions and others by studying advanced algorithmic techniques like randomization, approximation, sketching, continuous optimization, spectral methods, and Fourier methods. Students will learn how to theoretically analyze and apply these techniques to problems in machine learning and data science. 

Prerequisites: This course is mathematically rigorous and is intended for graduate students or strong, advanced undergraduates. We require a previous course in machine learning (for example, CS-UY 4563, CS-GY 6923, or ECE-GY 6143) and a previous course in algorithm design and analysis (for example, CS-UY 2413, or CS-GY 6033, CS-GY 6043). Experience with linear algebra and probability is also necessary. Email the course instructor if you have questions about your preparation for the course.

Topics: 

14 weeks total:

- Probability review (1 week)
    - expectation, variance, basis concentration bounds
    - randomness as a computational tool

- First order optimization (3 weeks)
    - continuous function optimization
        - applications: empirical risk minimization, convex functions (l2 regression, logistic regression, etc.)
    - gradient descent, stochastic gradient descent, online gradient descent
    - analysis for convex functions
        maybe something about strong convexity/smoothness to get tighter bounds
    - coordinate descent
    - improving gradient descent
        - acceleration
        - adaptive methods/preconditioning
        - Newtons method, quasi-newton methods, L-BFGS
    - non-convex problems: alternating minimization, gradient descent on neural networks, current theories (guest lecture?)

- Randomized algorithms (3 weeks)
    - probability and concentration bounds + applications
        - k-means++? This doesn't require anything beyond linearity of expectation maybe?
        - streaming algorithms (distinct elements, heavy hitters)
        - hashing for Jaccard similarity
        - streaming quantiles?
    - locality sensitive hashing / near neighbor search
    - Johnson-Lindenstrauss lemma + applications

- Constrained Optimization (2 weeks)
    - linear Programming
        - applications: support vectors machines, l1 minimization (lasso) for sparsity
    - simplex, ellipsoid, interior point methods (need a less heavy way to do this)

- Spectral methods (2 weeks)
    - singular value decomposition, eigendecomposition
        - example applications: compression, denoising, spectral clustering motivated by stochastic block model
    - power method, gradient descent on non-convex function, Oja's method 
        - doing better with acceleration (Krylov) and randomization
    
- Fourier methods (2 weeks)
    - the Fourier transform
        - example applications: compression, denoising, filtering (think of some more unique stuff here)
            - time series analysis
        - the FFT
    - compressed sensing, restricted isometry property, l1 minimization/basis pursuit
    - random Fourier features?

- Distributed computation models?
    - MapReduce, sketching, etc.?

- Case studies/putting it all together:
    1) the Shazam problem (Fourier methods, embedding, LSH)
    2) ...
    3) ...
